# Momentum downloads

Installers for **Momentum**, the private habit tracker in Arabic and English.

- **Windows:** [Momentum-Setup.exe](https://github.com/ahmedelkfrawy4/momentum-releases/releases/latest/download/Momentum-Setup.exe)
- **macOS:** [Momentum-mac.dmg](https://github.com/ahmedelkfrawy4/momentum-releases/releases/latest/download/Momentum-mac.dmg). The first time, right-click Momentum and choose Open.

All versions are on the [Releases](https://github.com/ahmedelkfrawy4/momentum-releases/releases) page.

[Privacy policy](https://ahmedelkfrawy4.github.io/momentum-releases/privacy.html) · Contact: info@ahmedelkfrawy.com

This repository only holds the installers and the public privacy policy. They are published automatically by the build.
